= F#OR (Operations Research with F#)
image::https://img.shields.io/badge/licence-MIT-blue.svg[LICENCE]

Library to solve operations research problems in F#. Build a model from
plain types, hand it to a solver, get a solution back. Currently wraps
https://developers.google.com/optimization[Google's OR-Tools] as the
underlying solver.

== Capabilities

* Linear and Mixed-Integer Programming (Google GLOP / CBC / SCIP via MPSolver)
* Constraint Programming (Google CP-SAT)

Routing examples are provided as direct OR-Tools usage; the routing API
is not currently wrapped by this library.

== Example
[source,fsharp]
----
open System
open Operations.Research.Types
open Operations.Research.Models
open Operations.Research.Solvers.Google.Linear

let x = Variable.real "x" 0.0 Double.PositiveInfinity
let y = Variable.real "y" 0.0 Double.PositiveInfinity

let mdl =
    Model.empty
    |> DecisionVars [x; y]
    |> Goal Maximize
    |> Objective (6.0*x + 2.0*y + 77.0)
    |> Constraints [
        3.0*x + 1.0*y <== 48.0
        3.0*x + 4.0*y <== 120.0
        3.0*x + 1.0*y >== 36.0
    ]

let sol = SolveWithCustomOptions mdl SolverOptions.Default

match sol.Status with
| Optimal ->
    printfn "Objective: %f" sol.Objective.Value
    printfn "x: %f" sol.Values.["x"]
    printfn "y: %f" sol.Values.["y"]
| status ->
    printfn "Solver did not reach optimal: %A" status
----

== Modelling

Variables come in three kinds:

[source,fsharp]
----
let a = Variable.boolean "a"               // domain {0, 1}
let b = Variable.integer "b" 0 100         // bounded integer
let c = Variable.integerFree "c"           // unbounded integer
let d = Variable.real    "d" 0.0 10.0      // bounded real
let e = Variable.realFree "e"              // unbounded real
----

Linear expressions compose via overloaded operators (`+`, `-`, `*`).
Constraints use comparison operators that produce `Constraint` values:

[source,fsharp]
----
let c1 = 1.0*x + 2.0*y <== 10.0      // less than or equal
let c2 = 1.0*x        >== 0.0        // greater than or equal
let c3 = 1.0*x + 1.0*y === 5.0       // equal
let c4 = 1.0*x =/= 4.0               // not equal (CP solver only)
let c5 = 1.0*x <-> (2.0, 8.0)        // bounded range
----

== Solver Selection

[source,fsharp]
----
// Linear / MIP
open Operations.Research.Solvers.Google.Linear
let sol = Solve mdl

// CP-SAT (integer-only domains, supports =/=)
open Operations.Research.Solvers.Google.Constraint
let sol = Solve mdl
----

Both solvers return `Solution { Status; Objective; Values }`. Inspect
`Status` (`Optimal`, `Feasible`, `Infeasible`, `Unbounded`, `NotSolved`)
before reading values.

== Installation

Download the latest release for your platform from the
https://github.com/acco32/Operations-Research/releases[Releases page].
Each release includes an `INSTALL.txt` file with detailed installation
instructions.

== Development

=== Prerequisites
* dotnet 10+
* https://github.com/rliebz/tusk[Tusk] task runner

=== Setup

Install the task runner:
[source,bash]
----
dotnet fsi tools/install-task-runner.fsx
----

Or use the tusk task (once tusk is installed):
[source,bash]
----
./tools/tusk install-tools
----

View available tasks:
[source,bash]
----
./tools/tusk
----

=== Building

Build the project:
[source,bash]
----
./tools/tusk build
----

Run tests:
[source,bash]
----
./tools/tusk test
----

=== Creating Releases

Build a release for a specific platform:
[source,bash]
----
./tools/tusk release -version=1.0.0 -runtime=linux-x64
----

Releases are automatically built and published to GitHub when you push a
version tag:
[source,bash]
----
git tag v1.0.0
git push origin v1.0.0
----

This creates platform-specific archives for download.
